3. Recommend safe cleaning actions.

{
  "summary": "...",
  "recommendations":[
    {
      "column":"Column Name",
      "issue":"Problem",
      "action":"Recommended action",
      "confidence":95,
      "risk":"Low"
    }
  ]
}

Do not invent dataset values.

Use only the provided issue information.
